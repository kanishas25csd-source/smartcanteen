SMART CANTEEN - PYTHON + DATA STRUCTURES + HTML/CSS

1. Install Flask:
   pip install flask

2. Open a terminal in the smart_canteen folder.

3. Run:
   python app.py

4. Open this address in your browser:
   http://127.0.0.1:5000/

IMPORTANT:
- No JavaScript is used.
- No Jinja template syntax is used.
- HTML forms send information to Python Flask routes.
- Python reads/writes orders.json, payments.json and feedback.json.
- The waiting-order queue uses collections.deque.
- Recent staff status changes use a Python list as a stack.
- Payment is only a demo. It does not transfer real money.
- Student profile details are stored for the current browser session.
